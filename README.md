# 🎯 Focus & ToDo (ポモドーロタイマー ＋ タスク管理アプリ)

作業への集中力を高める**ポモドーロタイマー**と、直感的に操作できる**ToDoタスク管理**をひとつにまとめた Android アプリケーションです。

---

## 📱 主な機能と使い方

### 1. ⏱️ ポモドーロタイマー機能
- **自動モード切替:** 作業時間（25分）と休憩時間（5分）がカウントダウン終了時に自動で交互に切り替わります。
- **完了セット数記録:** 作業時間を達成するごとに `🍅 完了: Xセット` がカウントアップされます。
- **時間調整 & プリセット:**
  - `+1分` `/` `-1分` `/` `+5分` `/` `-5分` ボタンで細かく時間を調整可能。
  - `15分`, `25分`, `50分` のワンタッププリセットチップ。
- **音 ＆ バイブレーション通知:** カウントダウンが0秒に達すると、通知音とスマホの振動でお知らせします。

---

### 2. 📝 ToDoタスク管理機能
- **タスクの追加 (最大15文字):** 
  - 入力フォームにタスク名を入力し、優先度（**高** / **中** / **低**）を選択して「追加」ボタンを押します。
  - 文字数はリアルタイムで `X/15` とカウント表示されます。
- **🎯 集中タスク指定:**
  - 各タスクの **「🎯 集中する」** ボタンをタップすると、そのタスクが集中対象として選択されます。
  - 選択中のタスクはカード全体がハイライトされ、タイマー上部に `🎯 集中作業中: [タスク名]` と固定表示されます。
- **タスクの完了 & 編集 & 削除:**
  - チェックボックスで完了（打消し線表示）/未完了を切り替え。
  - ✏️（編集アイコン）でタスク名や優先度を後からダイアログで修正。
  - 🗑️（ゴミ箱アイコン）で個別に削除。

---

### 3. 🔍 フィルタリング & 一括操作
- **表示切り替え:** 「すべて」「未完了」「完了済み」のチップをタップして一覧をフィルタリングできます。
- **完了済みを一括消去:** 「完了を消去」ボタンで完了したタスクをまとめて整理できます。

---

### 4. 💾 データ自動保存（永続化）
- アプリを終了したりスマホを再起動しても、作成したタスクや完了状態、優先度データは自動的に端末内に保存・復元されます。

---

## 🛠 技術スタック・アーキテクチャ

- **開発言語:** Kotlin
- **UI フレームワーク:** Jetpack Compose (Material 3)
- **アーキテクチャ:** MVVM (Model-View-ViewModel) + Repository パターン
- **非同期・状態管理:** Kotlin Coroutines / StateFlow / SharedFlow
- **データ永続化:** SharedPreferences + org.json
- **動作環境:** Android 11 (API レベル 30) 以上

---

## 🚀 開発・実行手順

1. **プロジェクトのビルド:**
   Android Studio でプロジェクトを開き、`Build` > `Rebuild Project` を実行します。
2. **アプリの実行:**
   実機端末または Android エミュレータを起動し、`Run 'app'` を実行します。
